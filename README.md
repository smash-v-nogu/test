# Тестовая сборка «Смэш мне в ногу»

https://smash-v-nogu.github.io/test/ — закрытая проверка новых ударов и биомеханики рук и ног с друзьями. Страница
зашифрована паролем (AES-256-GCM, ключ PBKDF2-SHA256, 600 000 итераций): в репозитории и в браузере без пароля лежит
только шифр. Пароль — у Кирилла. Регистр букв и пробелы по краям не важны. После входа ключ запоминается в браузере.

## Страница входа

- Глазик в поле пароля показывает, что введено: видно чужую раскладку, автозамену и пароль, подставленный браузером.
- В подвале — ветка, коммит и время сборки: по нему видно, какая сборка открыта.
- Устаревшая страница сама подтягивает свежую. Вкладку могли открыть до пересборки, а GitHub Pages разрешает
  браузеру держать страницу в кэше 10 минут. Старый шифр с тем же паролем молча открыл бы прошлую сборку, с другим
  ответил бы «Не тот пароль». Поэтому перед расшифровкой страница сверяет id сборки с `build.txt` (в обход кэша)
  и, если он другой, берёт шифр со свежей страницы.
- В расшифрованную игру страница входа вставляет возврат прокрутки. После экранной клавиатуры (пароль, код комнаты,
  имя) Safari на айфоне может оставить страницу сдвинутой, и тогда касания попадают мимо кнопок: реакция уходит
  соседняя, стрелки не нажимаются. Так починка работает без пересборки шифра. В самой игре она тоже есть,
  начиная с `wip/slowmo` 20.11.

## Тестовый режим

Основная игра не меняется: `build.mjs` правит копию `index.html` только для этой страницы.

- Общая база выключена: матчи, рекорды, лобби и вход по ПИНу не работают. Из запросов к Supabase пропускаются только
  ключи ретранслятора (функция `turn`): онлайн соединяется и через мобильный интернет или VPN.
- Свой профиль: ключи `localStorage` с суффиксом `-test`. Адрес тот же, что у основного сайта, и без суффикса тест
  смешался бы с профилем основной игры.
- Свои комнаты: префикс PeerJS `bdm-test-26-`. Играть с другом — по коду комнаты, лобби нет.
- Плашка «ТЕСТ» на экране и «ТЕСТ ·» в заголовке вкладки.

## Пересобрать

```bash
node build.mjs '/путь/к/ветке/index.html'
git add -A && git commit -m 'Rebuild from <ветка> <коммит>' && git push
```

Пароль сборка берёт из Связки ключей мака (запись `smash-v-nogu-test`), поэтому человек у терминала не нужен. Положить
пароль туда один раз: `node build.mjs --save-pass`. Пароль виден, пока его набираешь, потом экран стирается. Сохраняется
он, только если открывает текущую сборку. Новый пароль для всех: `--save-pass --new`, потом сборка с `--new-pass`.
Без этого флага сборка с паролем, который не открывает текущую страницу, останавливается: иначе всем, кто уже входил,
пришлось бы вводить пароль заново. `TEST_PASS='пароль'` по-прежнему работает и важнее Связки.

Сборка пишет `index.html` и `build.txt`, коммитить нужно оба. Пароль она не показывает, только сводку:
«Пароль: 8 знаков, латиница». Если стоит «кириллица», а пароль латинский, значит, его набрали в другой раскладке.

Поменялась только страница входа (`gate.html`): `node build.mjs --gate` заворачивает в неё готовый шифр, пароль не нужен.

Соль общая для всех сборок, поэтому после пересборки с тем же паролем вводить его заново не придётся. Если код игры
изменился так, что правка не нашлась, сборка остановится и назовёт эту правку.
